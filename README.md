# YouTube Trending Videos & Audience Sentiment Analysis

Conducted large-scale YouTube data analysis using Python, Pandas, TextBlob, Plotly, and SQLite on 300K+ trending videos and 690K+ user comments. Applied NLP-based sentiment analysis, word cloud generation, emoji analytics, and engagement-rate modeling to uncover audience sentiment, content performance trends, and key factors influencing video popularity across multiple countries.
